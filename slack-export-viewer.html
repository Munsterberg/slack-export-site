      Convert Slack export JSON to CSV

      1. In Slack, open workspace settings and choose Import/Export. Download the export. You need to be an owner or admin.
      2. Drop the ZIP here, or unzip it and drop a channel folder of JSON files.
      3. Pick a channel, search if you need to, and download CSV or Markdown.

      Slack's own export is not a spreadsheet. The ZIP holds one folder per conversation. Each day of messages is a JSON file, and users.json lists people, so an ID such as U0… can be shown as a name. A mention is stored as <@U0…>. This Slack export viewer reads that structure and fills in the names.

      On Free and Pro plans, the export only includes public channels. Private channels and direct messages are left out. Including them takes a Business+ or Enterprise Grid workspace, and an owner or admin still has to run the export.

      CSV has one row per message: timestamp in ISO format, user, text, thread_ts, and reply_count. Markdown is grouped by day. The file is parsed in this tab. It is not uploaded, and this tool does not set a cookie.

      Export a channel, DM, or thread without an admin

      Slack's export is the wrong tool when you just need one conversation, or when you aren't an owner. Channel Export is a Chrome extension that saves a channel, direct message, group DM, or thread you can already open. It does not need a workspace export or admin rights.

      Add it from the Chrome Web Store, open the conversation at app.slack.com, and click Export. Markdown and CSV save to your computer.

      Questions

      Why is a Slack export JSON?

      Slack writes each day of a channel as a JSON file of messages, and lists people in users.json. It is the workspace data export from Settings, then Import/Export, not a CSV. This viewer turns that JSON into a readable list, a CSV, or Markdown.

      Why are private channels and DMs missing from my export?

      An export from a Free or Pro workspace only includes public channels. Private channels and direct messages are included only when an owner or admin exports a Business+ or Enterprise Grid workspace. If you can open the conversation yourself, the Channel Export extension can save it without that admin export.

      Does this page upload my export?

      No. The ZIP or JSON is read in your browser. Messages are not sent to a server. Downloaded CSV and Markdown files go to your computer.

      How do I convert Slack export JSON to CSV?

      Drop the export ZIP, or the dated JSON files from a channel folder. Pick the channel and choose Download CSV. Each message is a row: timestamp (ISO), user, text, thread_ts, and reply_count. User IDs are replaced with names when users.json is in the export, and <@U…> mentions are filled in.

      What if the file is very large?

      The page reads it locally and shows the first messages, then more when you ask. A huge ZIP can still use a lot of memory and make the tab slow. If that happens, unzip the export and drop one channel folder instead of the whole workspace.

      Can I export a Slack channel without admin access?

      Not with Slack's own export. That file is only for owners and admins. Channel Export runs in Chrome on conversations you can already see, including channels, DMs, and threads, and saves Markdown or CSV on your computer.
