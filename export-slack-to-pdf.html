How to export a Slack conversation to PDF

Slack has no built-in way to save a channel, a DM, or a thread as a PDF. Channel Export does, for any conversation you can already open. Markdown and CSV are free. PDF is in the one-time $7 Full export.

Add to Chrome, free For Slack in Chrome, at app.slack.com

Steps

  1. Add Channel Export to Chrome.
  2. Open the channel, DM, or thread at app.slack.com in Chrome.
  3. Click Export and choose PDF.
  4. In Chrome's print dialog, pick Save as PDF. PDF is in the $7 Full export. Markdown and CSV stay free.

Slack has no built-in PDF export. Nothing on a channel, a DM, or a thread saves the conversation as a PDF. The export Slack does offer is for workspace owners and admins only, and it produces JSON, not a PDF. A regular member cannot run it. An admin who runs it gets a data export of the workspace, not a document of the one conversation that is open, and someone still has to turn that JSON into something a person can read.

Short of that, people print the conversation, screenshot it, or ask an admin. Each option is fine for a few messages and a poor fit for a longer one.

To print a Slack conversation, or to Save as PDF from the browser, open the channel or DM in Slack on the web and print from the browser. Slack loads history as you scroll, so the page only holds the messages that have already loaded. A long channel or DM prints as a short slice. Thread replies you have not opened are easy to miss, and the file is a print of the Slack window rather than a transcript Slack prepared. Covering the rest means scrolling, waiting, and printing again.

A screenshot is enough for a single message. A thread, or a channel you want to keep, turns into a stack of images. You cannot search them as text, messages get cut at the edge of a shot, and you have to wait while Slack loads the next stretch of history.

Channel Export is a Chrome extension that saves the conversation you can already see. Install it from the Chrome Web Store, open the channel, DM, or thread in Slack in Chrome, and choose PDF.

The free tier exports Markdown and CSV, with no message limits and no account. Markdown is a readable document with names, timestamps, thread replies, reactions, and links back to files. CSV is one row per message. In a free export, files are linked back to Slack.

PDF is in Full export, a single $7 payment, not a subscription. Full export adds HTML with images, files, avatars, and custom emoji, in a ZIP that works offline, PDF through Chrome's Save as PDF, the files and images downloaded into the export, and exporting several conversations at once.

Choose PDF in the export form and the extension opens the conversation in a tab for Chrome's print dialog. Pick Save as PDF there. The same dialog is what prints the conversation on paper. A PDF is held briefly in the extension's own storage for Chrome's print dialog, then deleted. The file you save stays on your computer.

You can export a channel, a private channel you're a member of, a 1:1 DM, a group DM, or a single thread. Click Export in the channel header or in the thread panel, or pick the conversation from the extension's toolbar popup. You can export all time, the last 30 days, or your own dates, and you can choose whether to include thread replies. In a thread, each reply is placed under the message it answers. Exporting DMs and exporting one thread use the same extension.

The export runs in your browser, using your own Slack sign-in. You do not need admin rights for conversations you can see, and nothing gets installed in your workspace. It never posts, edits, or deletes anything. We have no server that receives your messages. The extension collects no analytics or usage data. The privacy policy has the details.

You get the same history Slack shows you. On paid Slack plans that's usually everything. On free Slack plans, Slack only shows the last 90 days, so the extension can't reach older messages either. It does not run inside the Slack desktop app, because browser extensions only run in a web browser. Open app.slack.com in Chrome, sign in to the same workspace, and export from there.

Questions

Can I export a DM to PDF?

Yes. If you can open the direct message in Slack, you can export it. That includes 1:1 DMs and group DMs. Choose PDF in the export form and the extension opens the conversation in a tab for Chrome's print dialog. Pick Save as PDF there. PDF is in the $7 Full export. Markdown and CSV stay free.

Does the PDF include threads?

You can export a single thread, with each reply placed under the message it answers, or export a channel and choose whether to include thread replies. Either can be saved as a PDF with Full export, through Chrome's Save as PDF.

Do I need to be a Slack admin?

No. Slack's built-in export is only for workspace owners and admins, and it produces JSON, not a PDF. Channel Export works for regular members. If you can open a conversation in Slack, you can export it. Nothing gets installed in your workspace.

Is the export private?

The export runs in your browser. We have no server that receives your messages. A PDF is held briefly in the extension's own storage for Chrome's print dialog, then deleted, and the file you save stays on your computer. The extension collects no analytics or usage data.
